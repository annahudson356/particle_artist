# Concept

This scene is a lonely cottage, surrounded by lanterns and trees, that seems to be caught in the middle of a snowstorm! Due to the scary storm that has come upon the cottage, the sun is blocked from view, therefore the only thing lighting the scene are the lanterns, which cast shadows on the surrounding area. The snow sways back and forth as the wind blows it, creating quite the weather spectacle.


## Features Implemented

### Major
1. Point-Light Shadows (5)

### Minor
1. Base Forces (2)
2. Per-particle phase variation (2)

This gives 9/20 feature points.
